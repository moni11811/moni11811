## How I work

- **Understand the symptom.** Reproduce the real problem and separate evidence from assumptions.
- **Communicate the impact.** Keep users and colleagues informed in language they can act on.
- **Fix the system, not only the moment.** Add documentation, tests, automation, or guardrails when a failure can recur.
- **Change the approach after failure.** An unchanged retry is not a strategy.
- **Stay resourceful.** Aim for reliable outcomes with practical use of time, tools, and budget.
